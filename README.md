Aplicação web de **Avaliação de filmes** desenvolvida com PHP, MySQL e Bootstrap. Criada durante o curso **Hora de Codar** da Udemy para praticar operações CRUD, integração com banco de dados e design responsivo.

---

## 📌 Sobre o Projeto
Projeto Desenvolvido para interagir com outras pessoas sobre filmes que você gostou.

- Backend: PHP + MySQL  
- Frontend: HTML, CSS e Bootstrap  

---

## 🚀 Tecnologias Utilizadas
- **PHP** – lógica de backend  
- **MySQL** – banco de dados  
- **Bootstrap** – frontend responsivo  
- **HTML / CSS** – estrutura e estilo  

---

## ⚙️ Funcionalidades
- ✅ Adicionar filmes
- ✅ Visualizar filmes e usuarios
- ✅ Atualizar informações dos filmes 
- ✅ Excluir filmes
